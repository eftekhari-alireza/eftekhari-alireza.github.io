Shannon Tidal Resource Explorer

Interactive web app for exploring the Shannon Estuary's tidal-current energy resource. Pick one of 30 turbine configurations, drag a threshold slider, click any cell to see its stats across every config, and download the underlying data — all in your browser.

Open in full screen ↗ Source code on GitHub

Stack: Python · Streamlit · Plotly · DIVAST 2D · Lewis et al. 2021 standardised power curve. Built as the companion to the Shannon Estuary tidal-energy paper (University of Galway, 2026).
